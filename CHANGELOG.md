All notable changes to the BetterSmelting mod will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] - 2025-06-11

### Added
- Initial release of BetterSmelting mod
- Configurable ore capacity for Smelters and Blast Furnaces (10-100)
- Configurable fuel capacity for Smelters and Blast Furnaces (20-100)
- Adjustable smelting speed multiplier (0.1x - 10x)
- Option to allow all ore types in Blast Furnace
- Server-side configuration synchronization
- Comprehensive in-game configuration via BepInEx Configuration Manager
- Support for both single-player and dedicated server environments

### Changed
- Default ore capacity increased from 10 to 20 for Blast Furnace
- Default fuel capacity increased from 20 to 30 for Blast Furnace
- Improved error handling and logging

### Fixed
- Fixed issue with configuration not saving properly in some cases
- Fixed compatibility with other mods that modify smelting behavior
